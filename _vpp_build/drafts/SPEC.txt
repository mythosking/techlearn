## 5. 配图语法（关键：会被编译成可编辑形状 + .drawio 源文件）

每个图块用下面这种 DSL，**不要用 mermaid、不要插入图片、不要画 ASCII 图**：

```
:::figure id=06-02-01 | name=数据包处理图与帧传递 | dir=TD
node n1 "dpdk-input" blue
node n2 "ethernet-input" teal
node n3 "ip4-lookup" amber
edge n1 -> n2 "frame"
edge n2 -> n3
edge n3 -> n1 dashed "回查"
:::
```

规则：
- `node <id> "<文字>" <色调>`，色调只能是 blue / teal / amber / purple / gray / red / green。
- `edge <from> -> <to> "<标签>"`；可加 `dashed` 表示辅助/回查关系；标签可省略。
- 节点文字用**双引号**包裹，内部不要出现双引号；可用 `<br/>` 换行。
- 节点 id 只用字母数字下划线，且必须唯一。
- **禁止** subgraph / classDef / style / 链接语法。
- 首行 `:::figure ...` 与末行 `:::` 必须各占一行。
- `id` 全局唯一，建议 `<篇章号>-<序号>`，如 `07-05-01`。
- 每篇至少 1 张图；整个文件图数不少于「篇数 / 2」向上取整，关键篇可 2 张。

也可正常使用标准 Markdown 表格、` ``` ` 代码块、`> ` 提示、有序/无序列表。

## 6. 分批写入策略（内容很大，务必分块）

- 之后每次用 Edit 把 `<!--NEXT-->` 替换为「后续 1–2 篇 + 新的 `<!--NEXT-->`」。
- 最后一批写完后，再 Edit **删除末尾哨兵**。
- 每批必须真实成文，一次 Edit 可写 2 篇以控制调用次数。
